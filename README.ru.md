# JoyBot 🤖

Добро пожаловать в JoyBot — профессионального Telegram-бота для доставки контента с joyreactor.cc на основе предпочтений пользователя и индивидуального расписания.

[English version 🇺🇸](./README.md)

## ✨ Возможности

- **Умная доставка**: Получайте свежие посты по команде `/next` или автоматически по вашему расписанию.
- **Продвинутая фильтрация**: Настраиваемые списки тегов «Разрешить» (Include) и «Исключить» (Exclude).
- **Личное расписание**: Настраивайте время и дни доставки с полной поддержкой часовых поясов.
- **Защита Rate-Limit**: Централизованная очередь API гарантирует соблюдение лимитов JoyReactor.
- **Production-Ready**: Распределенные блокировки для предотвращения дублей, автоочистка кэша и структурированное логирование.
- **Приватность**: Полное удаление данных с 30-дневным периодом восстановления.

## 🚀 Быстрый старт

### Переменные окружения
Создайте файл `.env` на основе `.env.example`:
- `BOT_TOKEN`: Токен вашего Telegram-бота.
- `DATABASE_URL`: Строка подключения к PostgreSQL.
- `REDIS_URL`: Строка подключения к Redis (для очередей и блокировок).
- `API_REQUEST_INTERVAL`: Мин. интервал между запросами к API (по умолчанию: 2.0).

### Установка
С помощью Docker (рекомендуется):
```bash
docker-compose up -d
```

Или ручная установка:
```bash
pip install -r requirements.txt
python main.py
```

## 🛠 Команды

- `/next` — получить следующий подходящий пост.
- `/settings` — управление тегами, расписанием и автоотправкой.
- `/search_tags <запрос>` — поиск канонических тегов на JoyReactor.
- `/stop` — остановить автоматическую рассылку для текущего чата.
- `/delete_my_data` — запросить полное удаление данных.
- `/restore` — отменить запрос на удаление.
- `/stats` — (Только для админов) статистика системы.
- `/force_send` — (Только для админов) принудительная отправка поста в текущий чат.

## 🏗 Архитектура

- **Язык**: Python 3.11+ (asyncio)
- **Фреймворк**: aiogram 3.x
- **База данных**: PostgreSQL 14+ (SQLAlchemy Async)
- **Очередь/Кэш**: Redis / Asyncio PriorityQueue
- **Медиа**: Pillow, FFmpeg (для оптимизации контента)
